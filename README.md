# Proyecto NoSQL – App de Hábitos y Rutina Diaria  
Equipo 2 – Sprint 1

## 1. Descripción del Proyecto  
La aplicación web “App de Hábitos y Rutina Diaria” permite a usuarios crear y gestionar sus hábitos, registrar su cumplimiento diario y visualizar su progresión semanal. Utiliza una base de datos NoSQL (MongoDB) para el almacenamiento, junto con un backend en Node.js + Express. El proyecto se desarrolla siguiendo la metodología Scrum.

## 2. Objetivo  
Como usuario quiero llevar un registro fácil de mis hábitos y mi rutina diaria para mejorar mi disciplina y constancia.

## 3. Alcance del Sprint 1  
- Crear la estructura básica del backend: conexión a MongoDB, servidor Express funcionando.  
- Definición de modelos de datos iniciales (Usuarios, Hábitos, Registros diarios).  
- Configuración del repositorio GitHub con ramas de trabajo, rol de equipo y herramientas instaladas.  
- Primera HU implementada: registro de usuario (HU-001).  
- Evidencia: captura del tablero Scrum, enlace a issues creados y captura del repositorio.
